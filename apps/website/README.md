# website

App Astro do monorepo `dia-zero`, preparado para deploy no Cloudflare.

## Stack atual

- deploy no **Cloudflare**
- Sitemap
- SEO com `astro-seo`
- JSON-LD com `astro-seo-schema`
- **PostHog** para analytics e logs
